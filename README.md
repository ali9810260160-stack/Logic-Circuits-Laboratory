## 📖 Overview

This repository contains the lab reports, schematics, and simulation files for the **Logic Circuits Laboratory** course at the Department of Computer Engineering, Sharif University of Technology.

The contents of this repository are based on the official lab manual prepared by the late **Eng. Hayedeh Motavalli** and revised by **Dr. Hossein Asadi** (Fall 2009).

The main goal of these experiments is to bridge the gap between theoretical knowledge and practical implementation. Students design, simulate, and physically implement various digital logic circuits using standard TTL and CMOS ICs.

## 🛠️ Simulation Tools Used

To ensure the accuracy of the designs before physical implementation, the following software tools are used in this repository:
*   **Proteus** (for microcontroller and mixed-signal circuit simulation)
*   **Fritzing** (for breadboard and physical wiring diagrams)
*   **Logisim** (for logic gate-level and architectural simulation)

## 📂 Repository Structure

*   `Lab-Reports/`: Detailed reports for each experiment (including theoretical background, block diagrams, pin diagrams, and final results).
*   `Simulations/`: Simulation files categorized by experiment number and software (.pdsprj for Proteus, .circ for Logisim, etc.).
*   `Datasheets/`: Reference datasheets for the ICs used in the labs (e.g., 7404, 7495, 74109, 555 Timer).
*   `Docs/`: General lab instructions and supplementary materials.

## 🔬 List of Experiments

Based on the lab manual, the course covers the following 11 experiments:

1.  **Experiment 1:** Familiarization with Lab Equipment and Catalog Usage.
2.  **Experiment 2:** NAND Gate Characteristics and Understanding Fan-out.
3.  **Experiment 3:** Variable Frequency Pulse Generator (using 555 Timer).
4.  **Experiment 4:** Shift Registers (using 7495).
5.  **Experiment 5:** Counters (using JK Flip-Flops and BCD Counters).
6.  **Experiment 6:** Washing Machine Timer (FSM Design).
7.  **Experiment 7:** Long-Distance Telephone (FSM Design with coin mechanism).
8.  **Experiment 8:** ALU, Registers, and Data Bus.
9.  **Experiment 9:** Hardware Stack Implementation.
10. **Experiment 10:** Design of a Simple Binary Computer.
11. **Experiment 11:** Review of Past Experiments & Makeup Sessions.

## 📝 Lab Report Guidelines

Each report in this repository follows the university guidelines, which minimally include:
*   A brief introduction and theoretical background.
*   Block diagrams and logic diagrams of the proposed design.
*   Pin diagrams for the final implementation.
*   Discussion of the results and reasoning behind any design changes.
