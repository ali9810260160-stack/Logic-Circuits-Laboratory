# آزمایشگاه مدار منطقی - دانشگاه صنعتی شریف

![دانشگاه صنعتی شریف](https://img.shields.io/badge/دانشگاه-صنعتی%20شریف-blue)

## 📖 معرفی

این مخزن (Repository) شامل گزارش‌های کار، نقشه‌های شماتیک و فایل‌های شبیه‌سازی مربوط به درس **آزمایشگاه مدار منطقی** دانشکده مهندسی کامپیوتر دانشگاه صنعتی شریف است.

محتوای این پروژه بر اساس دستور کار رسمی آزمایشگاه، تهیه و تدوین **زنده‌یاد مهندس هایده متولی** و بازنگری **دکتر حسین اسدی** (پاییز ۱۳۸۸) گردآوری شده است.

هدف اصلی این آزمایش‌ها، ایجاد پیوند بین دانش نظری و پیاده‌سازی عملی است. دانشجویان در این درس مدارهای منطقی مختلف را با استفاده از تراشه‌های استاندارد سری TTL و CMOS طراحی، شبیه‌سازی و به صورت فیزیکی پیاده‌سازی می‌کنند.

## 🛠️ نرم‌افزارهای شبیه‌سازی استفاده شده

برای اطمینان از صحت عملکرد مدارها پیش از پیاده‌سازی فیزیکی، از نرم‌افزارهای زیر در این مخزن استفاده شده است:
*   **پروتئوس (Proteus)**: برای شبیه‌سازی مدارات میکروکنترلری و ترکیبی.
*   **فریتزینگ (Fritzing)**: برای رسم دیاگرام‌های بردبورد و سیم‌بندی فیزیکی.
*   **لاجی‌سیم (Logisim)**: برای شبیه‌سازی در سطح گیت‌های منطقی و معماری.

## 📂 ساختار مخزن

*   `Lab-Reports/`: گزارش‌های کامل هر آزمایش (شامل مقدمه نظری، بلوک دیاگرام، پین‌دیاگرام و نتایج نهایی).
*   `Simulations/`: فایل‌های شبیه‌سازی دسته‌بندی شده بر اساس شماره آزمایش و نوع نرم‌افزار (مانند `.pdsprj` برای پروتئوس و `.circ` برای لاجی‌سیم).
*   `Datasheets/`: دیتاشیت تراشه‌های مورد استفاده در آزمایشگاه (مانند ۷۴۰۴، ۷۴۹۵، ۷۴۱۰۹ و تایمر ۵۵۵).
*   `Docs/`: دستور کار کلی و مطالب تکمیلی آزمایشگاه.

## 🔬 لیست آزمایش‌ها

بر اساس دستور کار، این دوره شامل ۱۱ آزمایش به شرح زیر است:

۱.  **آزمایش ۱:** آشنایی با تجهیزات آزمایشگاه و نحوه استفاده از کاتالوگ‌ها.
۲.  **آزمایش ۲:** مشخصه گیت NAND و آشنایی با مفهوم Fan-out.
۳.  **آزمایش ۳:** پالس ژنراتور با فرکانس متغیر (با استفاده از تایمر ۵۵۵).
۴.  **آزمایش ۴:** شیفت رجیسترها (با استفاده از تراشه ۷۴۹۵).
۵.  **آزمایش ۵:** شمارنده‌ها (با استفاده از فلیپ‌فلاپ‌های JK و شمارنده‌های BCD).
۶.  **آزمایش ۶:** تایمر ماشین لباسشویی (طراحی ماشین حالت - FSM).
۷.  **آزمایش ۷:** تلفن راه دور (طراحی FSM با مکانیزم دریافت سکه).
۸.  **آزمایش ۸:** آشنایی با ALU، ثبات‌ها و گذرگاه داده.
۹.  **آزمایش ۹:** پیاده‌سازی پشته (Stack) سخت‌افزاری.
۱۰. **آزمایش ۱۰:** طراحی یک کامپیوتر دودویی ساده.
۱۱. **آزمایش ۱۱:** مرور آزمایش‌های گذشته و انجام آزمایش‌های معوقه.
